# Ennui's Bigger Intro

Ennui's Bigger Intro is a starter modpack for [Ennui's Bigger Inventories](https://github.com/EnnuiL/ennuis_bigger_inventories), with one focused goal: provide players with a minimal base so they can enjoy having The Inventory Problem solved in the simplest and most convenient way possible!

See more on the [Modrinth page](https://modrinth.com/modpack/ennuis_bigger_intro)!
